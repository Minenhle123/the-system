Privacy

We collect nothing

Not “nothing personal”. Nothing. There is no server for your data to go to.

What we collect

None. THE SYSTEM is a set of static files: HTML, CSS and JavaScript. Once they load, the app runs entirely in your browser. There are no accounts, no cookies, no analytics, no tracking pixels, no advertising and no third-party scripts. The app never sends your quests, progress or name anywhere.

The only outside request is for the two typefaces, which load from Google Fonts. That request tells Google your IP address and that a page asked for those fonts, as any website using Google Fonts does. It does not include anything about you or your progress.

Where your progress is stored

Your hunter is saved in your browser's local storage on your device. If you use the save-file feature, it is also in a file on your device that you chose. If you install the app, a copy of the site's files is cached so it works offline. That is everything.

Local storage belongs to this exact web address. If the site ever moves to a different address, your progress will not follow it. Before that happened you would need to save to a file at the old address and load it at the new one. A save file is a good habit anyway.

Exporting and deleting

  • Export: in the app, Settings → Save to file. The file is readable JSON and yours to keep.
  • Delete: Settings → Erase all data removes everything this site has stored in your browser. Clearing this site's data in your browser settings does the same.

We cannot recover a hunter you erase, because we never had a copy.
